CRM SALES KPI DASHBOARD SUITE

Coverage: January 2024 through December 2026 (36 months)
Design: Modern dark executive dashboard

Excel
- Open CRM_Sales_KPI_Dashboard.xlsx.
- Choose a month from the SELECT MONTH dropdown on Dashboard.
- KPI cards compare Actual, Target and Previous Year.
- Charts cover revenue trend, sales funnel and sales-rep performance.
- Replace sample rows in the three data sheets while preserving the table structure.

Power BI
- Open the PowerBI folder and follow README.txt.
- Includes import-ready CSV files, DAX measures and a dark JSON theme.

Tableau
- Open the Tableau folder and follow README.txt.
- Includes a .twb starter workbook and local CSV data sources.

Core KPIs
New Leads, Qualified Leads, Opportunities, Won Deals, Won Revenue, Revenue Target, Pipeline Value, Win Rate, Target Attainment, Average Deal Size and Sales Cycle Days.
