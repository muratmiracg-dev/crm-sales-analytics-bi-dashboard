TABLEAU CRM DASHBOARD

1. Place CRM_Sales_Dashboard.twb and crm_monthly.csv in the same folder, then open the workbook.
2. If prompted, Edit Connection and select crm_monthly.csv.
3. Add crm_rep_performance.csv and crm_lead_sources.csv as related logical tables on Month.
4. Use Month Key as a single-value filter.
5. Build KPI sheets for New Leads, Won Revenue, Pipeline and Win Rate; show Target and PY in labels.
6. Add revenue line chart, funnel bars, rep revenue-vs-target bars and lead-source table to the dashboard.
7. Modern dark palette: #07111F background, #101D2E panels, #24C7D9 leads, #39D98A revenue, #4F7CFF pipeline, #FFB547 rates.
